# 开发日志说明

本目录按天记录本项目的开发进展，一天一个文件，命名 `YYYY-MM-DD.md`。

## 固定结构

```markdown
# YYYY-MM-DD 开发日志

## 今日完成
- [阶段编号] 事项 —— 验证方式

## 待办事项
- [阶段编号] 事项

## 遇到的问题
- 现象 → 原因 → 处理

## 下轮计划
- 从哪个阶段编号开始；需要用户配合的动作
```

## 规则

1. **只有已验证的事项才能写进"今日完成"**，并必须注明验证方式（编译通过 / 自检报告 / 用户实测）。
2. 未跑通的一律写进"待办事项"，并标注归属阶段编号。
3. 每轮收工同步更新 `docs/04-开发执行步骤.md` 的进度追踪表。
4. 日志只记录事实，不做主观评价。

## 阶段编号

与 `docs/04-开发执行步骤.md` 一致：`S0` 项目基建、`S1` 编译链路与内存内核、`S2` 扫描与配置、`S3` 校准向导、`S4` 核心三项、`S5` 界面与热键、`S6` 扩展三项、`S7` 联机模式、`S8` 交付。
