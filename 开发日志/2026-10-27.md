## 今日完成

- **[开源核查]** 对照 GitHub 仓库、git 历史与工作区，逐项核对"公开源码"到"开源"还差什么 ——
  验证方式：GitHub API 查询 + `git ls-files` / `git grep` 全量扫描 + 全历史 blob 检查。
  **结论**：仓库已公开（`github.com/micaholic125/MO-Trainer`），但 **GitHub 显示 `license: null`**，
  即法律上仍是"保留所有权利"，别人不能合法复制 / 修改 / 再发布。另外 **根目录没有 README**，
  访客第一眼看到的是文件清单。

  同时确认了几件**不需要处理**的事（避免重复调研）：
  ① 无任何第三方代码 / 库（C# 只用 .NET Framework 自带类库与 Win32 API；`tools/*.py` 只用标准库）
  → 不需要第三方许可文件；
  ② 仓库内无游戏文件、图片、音频 → 不存在游戏素材再分发问题；
  ③ 全历史未发现密钥、密码、个人电脑路径（只有作者主动公开的 QQ 邮箱与抖音号）；
  ④ 已有一个正式发布 `v1.0.3` + zip + SHA256。

- **[开源声明] 新增 `LICENSE`（GPL-3.0）** —— 验证方式：与 gnu.org 官方文本逐字节比对。
  版权人按用户选择写为 `micaholic125`，年份 2026。文件结构 = FSF 推荐的程序声明（含
  "either version 3, or any later version"）+ GPL-3.0 全文（**`cmp` 与
  `https://www.gnu.org/licenses/gpl-3.0.txt` 完全一致，674 行 / 35 149 字节**）。

- **[README] 新增根目录 `README.md`** —— 验证方式：内容逐条对照源码与 `docs/` 核对；
  本轮未改代码，`build.ps1 -Check` 判定产物未过期（exit 0）。
  语言按用户选择为**中文为主 + 英文摘要**。含：项目简介、功能与热键表、系统要求、下载与三步上手、
  校准数据说明、安全与使用范围、已知限制、常见问题、从源码编译（含 C# 5 硬约束）、仓库结构、
  参与贡献、许可证、免责声明、联系方式。
  **职责划分**：README 面向"第一次打开仓库的人"；逐功能细节仍以 `docs\使用说明.docx` 为准。
