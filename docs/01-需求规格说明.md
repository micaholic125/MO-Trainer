# 01 需求规格说明

> 版本 v1.0 ｜ 建立 2026-09-20 ｜ 适用产品：MO-Trainer（心灵终结实时修改器）
> 上游来源：用户口述需求 + 需求澄清问答（2026-09-20）

---

## 1. 目标

为《心灵终结》（Mental Omega 3.3.6）提供一款 **Windows 免安装实时修改器**，让不具备任何编程知识的用户，双击即可在单人 / 自建局域网对局中修改游戏内数值与战斗状态。

## 4. 功能需求

### FR-01 自动识别与连接
- 自动查找正在运行的 `gamemd.exe`，建立内存读写句柄。
- 顶部状态条显示：未运行 / 已连接 / 读取失败，并显示模块基址。
- 游戏关闭后自动掉线，重新启动游戏后**自动重连**，无需用户干预。
- 验收：手动开关游戏 3 次，状态条均能在 3 秒内正确反映。

### FR-02 金钱修改
- 开关式锁定。用户可输入目标金额，开启后游戏内金钱**持续保持**该值。
- 界面实时回显当前实际读到的金钱值。
- 验收：开启后游戏内建造、花钱，金额 2 秒内恢复到设定值；关闭后恢复正常。

### FR-03 电力修改
- 开关式锁定。开启后电力始终充足，不再出现低电力导致的建造/生产降速与断电停摆。
- 验收：开启后建造大量耗电建筑，界面电力条不进入红色告警状态。

### FR-04 选中单位无敌（热键触发）
- 用户在游戏内框选单位后，按热键或点击按钮，被选中单位进入无敌状态。
- 支持解除（反向操作），避免误开后无法收回。
- 验收：对选中单位使用后，承受敌方集火 30 秒无掉血、无死亡。

### FR-05 秒杀敌人
- 一键消灭场上所有敌方单位与建筑。
- **必须二次确认**，防止误触。
- 验收：确认后 3 秒内敌方单位数量归零。

### FR-06 瞬间建造 / 生产秒出
- 开关式锁定。建筑与单位的生产进度直接完成。
- 验收：开启后任意建造项在 1 秒内完成。

### FR-07 全图视野
- 开关式锁定。去除未探索黑幕与战争迷雾。
- 验收：开启后全图可见，关闭后恢复。

### FR-08 三种运行模式
| 模式 | 行为 |
| --- | --- |
| 单人模式（默认） | 全部功能开放 |
| 局域网友好模式 | 默认只开放低风险项；高风险项需二次确认 + 显著红色警示 |
| 全员同步模式（实验性） | 所有玩家均运行本工具时，由房主通过 UDP 广播统一开关与目标值，**降低**（非消除）不同步概率 |

### FR-09 交互与热键
- 所有功能均可鼠标点击开关。
- 常用功能支持**全局热键**，游戏中无需切出即可操作。
- 界面内提供热键速查。

### FR-10 首次校准向导
- 独立页面，引导用户完成一次性地址校准。
- 自动定位金钱与电力字段，并生成人类可读的**校准报告文件**供回传分析。
- 验收：新用户可在无技术指导的情况下，按提示 5 分钟内完成校准。

### FR-11 记录与配置
- 运行日志按天切分，保留最近 7 份。
- 校准结果持久化，重启后无需重新校准。
- 全部文件保存在工具自身目录，**不写注册表、不写 C 盘**。

## 5. 非功能需求

| 编号 | 要求 |

| NFR-06 | 界面一屏之内看清全部功能与当前状态；开启状态有明确颜色反馈 |

## 6. 明确的边界（Out of Scope）

- ❌ 不支持公网 CnCNet 联机（有榜单与公平性规则，属违规）。
- ❌ 不做 DLL 注入 / 代码 patch / 反反作弊绕过。
- ❌ 不修改游戏目录下的任何游戏文件（不改 INI、不改 MIX）。
- ❌ 不提供"修改他人客户端"的能力。
- ❌ 不做自动更新、不做联网上传。

## 7. 已知风险与免责

1. **局域网不同步风险**：YR 引擎是帧同步架构。金钱、电力、全图视野属低风险；**选中无敌 / 秒杀敌人 / 瞬间建造属高风险，单方面修改必然触发 "out of sync" 掉线**。工具将按风险分级并对高风险项强制二次确认。
2. **版本变更风险**：MO 后续更新可能改变数据结构。工具采用 AOB 特征扫描 + 运行时校验，失效时自动降级提示重新校准。
3. **地址不可预知**：所有内存地址必须经用户真机实测校验后固化，**不得凭公开资料直接写死**。
