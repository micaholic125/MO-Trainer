## 1. UI 视觉规范

**字体**：`Microsoft YaHei UI`

| 角色 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| Heading | 22 px（16.5 pt） | 600 | 页面标题 |
| Subheading | 15 px（11.25 pt） | 500 | 卡片标题 |

**度量**：圆角 8 px（卡片）/ 12 px（开关滑块容器）；间距梯度 4 / 8 / 12 / 16 / 24 px；卡片内边距 16 px；卡片间距 12 px；导航栏宽 180 px；状态条高 56 px；日志区高 120 px。

### 1.2 布局规范

- 默认窗口 1000 × 660，最小 880 × 580，可自由缩放。
- 导航项：主控台 / 高级功能 / 联机模式 / 校准向导 / 关于。
- 选中导航项：左侧 3 px 强调色指示条 + `Bg2` 底色。

### 1.3 组件规范

| 组件 | 规范 |
| --- | --- |
| `ToggleSwitch` | 自绘滑块，宽 52 / 高 28；关闭态滑块在左，开启态在右；**150 ms 平滑位移动画**；开启配色 `Primary`，关闭 `Bg2` + `Border` 描边；禁用态整体 40% 透明度 |
| `CardPanel` | 圆角 8 px、1 px `Border` 描边、`Bg1` 底；悬停时描边与底色 **120 ms 渐变提亮**；左上角可带风险色标条（绿/红，宽 3 px） |
| `StatusStripView` | 左侧连接状态圆点（● 8 px） + 文本；圆点颜色 = `Success` 已连接 / `Warning` 未运行 / `Danger` 错误 |
| `LogView` | 等宽字体；Debug = `Text2`，Info = `Text1`，Warn = `Warning`，Error = `Danger`；自动滚到底；超过 500 行丢弃最旧 |
| 数值回显 | 使用 Mono 字体；数值变化时数字**上浮 2 px 并闪动一次**（约 200 ms） |

### 1.4 交互规范

- 开关点击即生效并立即变色，**不做异步等待**。
- 高风险操作（秒杀敌人、联机下开启高危项）**必须二次确认弹窗**，弹窗主按钮为 `Danger` 色。
- 内存读写失败 / 地址校验失败：状态条与日志**同步橙色告警**，并在页面提供"重新校准"快捷入口。
- 全局热键在游戏中可直接触发"选中无敌""一键全关"；全屏游戏首次运行时自动提示切换窗口化。

## 2. C# 代码规范

### 2.1 语法约束（编译器限制，必须遵守）

编译器为 .NET Framework 4.8 内置 `csc.exe`，**仅支持 C# 5**。**禁止使用**：

| 禁止 | 替代 |
| --- | --- |
| 字符串插值 `$"x={a}"` | `string.Format("x={0}", a)` 或 `"x=" + a` |
| 表达式体成员 `int X => 1;` | 完整 `get { return 1; }` |
| `nameof(x)` | 字面量 `"x"` |
| `?.` / `?[` | 显式 `if (a != null)` |
| `out var x` | 先声明 `int x;` |
| 属性初始化器 `public int X { get; set; } = 1;` | 构造函数内赋值 |
| `using static` | 写全限定名或 using 别名 |
| 异常筛选器 `catch (Ex e) when (...)` | `catch` 内判断并 `throw` |

源文件一律 UTF-8；编译必须带 `/codepage:65001`。

### 2.2 命名与组织

| 项 | 规范 |
| --- | --- |
| 命名空间 | `MoTrainer` / `MoTrainer.Core` / `MoTrainer.Cheats` / `MoTrainer.Ui` / `MoTrainer.Util` / `MoTrainer.Calibration` / `MoTrainer.Net` / `MoTrainer.Diagnostics` |
| 类 / 方法 / 属性 | PascalCase |
| 私有字段 | `_camelCase` |
| 常量 | `PascalCase` |
| 一个文件一个主类型 | 允许同文件放置紧耦合的小型辅助类型 |
| 文件编码 | UTF-8 无 BOM |

### 2.3 写法要求

- **所有 P/Invoke 返回值必须检查**；失败走统一的 `Logger.Warn/Error`，不得静默忽略。
- 内存读写必须走 `MemoryIO` 单一入口，**禁止在业务代码里直接调 `ReadProcessMemory`**。
- 地址计算必须走 `PointerChain` / `CalibrationProfile`，**禁止在作弊模块里硬编码魔法数字偏移**（偏移必须来自 profile 或具名常量并附注释）。
- 关键写入后**立即回读校验**，不一致重试一次并记录。
- 后台线程必须设置 `IsBackground = true`，并在 `Dispose` 中正确停止。
- 所有 `IDisposable` 必须在 `using` 或显式 `finally` 中释放。
- 注释用中文，只解释"为什么"，不复述"做了什么"。

### 2.4 异常处理

- UI 线程：`Program.cs` 注册 `Application.ThreadException` + `AppDomain.UnhandledException` 兜底，弹中文错误框并写日志，**不允许白屏或静默退出**。
- 后台线程：所有 `Tick` 内部包裹 try/catch，单次异常只记日志并计数，连续失败 N 次自动停用该功能，避免刷屏。

## 3. 日志规范

| 级别 | 用途 | 示例 |
| --- | --- | --- |
| Debug | 原始数值转储，便于远程排查 | `read money = 12345 @ 0x00A9B1C0` |
| Info | 状态变化、功能启停、校准步骤 | `Cheat Money enabled` |
| Warn | 可恢复异常、校验失败、降级 | `write verify failed, retry once` |
| Error | 不可恢复错误 | `OpenProcess failed, win32=5` |

- 文件：`<exe目录>\logs\trainer-YYYYMMDD.log`，按天切分，保留最近 7 份。
- 单条格式：`HH:mm:ss.fff [级别] [来源] 内容`。
- **严禁记录与项目无关的个人信息**；不得出现用户目录之外的路径。

## 4. 文件与配置规范

| 文件 | 位置 | 说明 |
| --- | --- | --- |
| 校准配置 | `<exe目录>\config\profile.json` | 地址定位结果 |
| 用户设置 | `<exe目录>\config\settings.json` | 热键、默认金额、运行模式 |
| 校准报告 | `<exe目录>\reports\calibration-YYYYMMDD-HHmmss.txt` | 人类可读，供用户回传 |
| 自检报告 | `<exe目录>\logs\selftest-*.log` | 控制台自检输出 |
| 运行日志 | `<exe目录>\logs\trainer-*.log` | 按天切分 |

**红线**：不写注册表、不写 C 盘、不改动游戏目录下的游戏文件。
