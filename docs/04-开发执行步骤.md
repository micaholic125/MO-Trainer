## S1 编译链路与内存内核（**风险最高的先做**）

> 目的：在任何功能开发之前，先证明"能编译出 exe"+"能和游戏进程对上话"。

| 编号 | 步骤 | 验收标准 |
| --- | --- | --- |
| S1-1 | `build.ps1` / `build.bat` 离线编译脚本，自动探测 `csc.exe`，`/codepage:65001`、`/platform:x64`、内嵌 manifest | 命令行执行输出 `BUILD OK`，`dist\MentalOmegaTrainer.exe` 存在 |
| S1-2 | `app.manifest`：`requireAdministrator` + per-monitor DPI | exe 属性页可见"以管理员身份运行"要求 |
| S1-3 | `Util\Logger.cs`：分级日志、按天切分、保留 7 份、UI 订阅回调 | 运行后生成 `logs\trainer-*.log` |
| S1-4 | `Core\Win32Api.cs`：RPM / WPM / VirtualQueryEx / EnumProcessModulesEx 等 P/Invoke 与结构体 | 编译通过，结构体在 x64 下尺寸正确（`MEMORY_BASIC_INFORMATION` = 48 字节） |
| S1-5 | `Core\ProcessAttach.cs`：按进程名查找 `gamemd.exe`、`LIST_MODULES_32BIT` 取模块基址、1.5 s 看门狗自动重连 | 游戏未运行时状态 = 未运行；运行时状态 = 已连接且基址 = `0x400000` |
| S1-6 | `Core\MemoryIO.cs`：单值/批量读写、可写页校验、区域枚举、失败重试 | 自检中读写往返一致 |
| S1-7 | `Diagnostics\SelfTest.cs`：控制台自检（不参与主程序编译），输出报告文件 | `dist\logs\selftest-*.log` 全部检查项 PASS |
| S1-8 | `Ui\Theme.cs` + `Ui\MainForm.cs`：深色扁平骨架（状态条 + 导航 + 内容区 + 日志区） | 双击 exe 能正常打开窗口，无异常 |

**验收方式**：运行 `build.ps1 -Test -RunTest`，检查自检报告。
